TrustScan — AI independence monitoring (project)

Prototype and documentation for TrustScan: a concept to check whether hospitals' AI imaging tools give truly independent second opinions.

This repository contains the TrustScan concept, a clickable dashboard prototype with made-up sample data, and supporting docs (SWOT, pitch deck, one-page summary, brand notes).

Quick start

  1. Open TrustScan/prototype.html in your browser (it's static; no install required).
  2. Try the Records tab to enter made-up cases and see how the prototype rates them.
  3. Download the audit log or records as CSV from the Reports/Records tabs.
